# Тренажёр «Напечатай слово»

Тренажёр для приложения [ЭМО](https://emo.su): пользователь видит картинку и подпись и печатает слово в поле ответа. После последнего вопроса показывается таблица с правильными ответами, ответами пользователя и результатом проверки.

Написан на чистых HTML, CSS и JS (ES-модули), без библиотек и сборщиков.

## Демо

Опубликован на GitHub Pages: <https://1ike.github.io/test-task-kreativdelo/>. Страница собирается из корня ветки `master`.

## Запуск

Данные загружаются из `data/trainer.json` через `fetch`. Браузеры не разрешают `fetch` и ES-модули по протоколу `file://`, поэтому при открытии `index.html` двойным кликом тренажёр не запустится и покажет подсказку. Откройте проект через локальный сервер:

```bash
npx serve
# или
python -m http.server
```

Затем открыть адрес, который выведет сервер (например, <http://localhost:3000>).

## Структура

```text
index.html             — страница с вопросами тренажёра
pages/answers.html     — страница с таблицей ответов
css/style.css          — общие стили обеих страниц
js/questions-page.js   — загрузка данных и прохождение вопросов
js/answers-page.js     — вывод таблицы ответов
js/results-storage.js  — передача результатов между страницами через sessionStorage
js/trainer.js          — логика тренажёра: перемешивание, ответы, доступ к страницам, проверка
js/views.js            — создание экранов вопроса и таблицы ответов
js/icons.js            — SVG-иконки галочки и крестика
data/trainer.json      — текст задания, картинки и правильные ответы
img/                   — изображения
fonts/                 — шрифты Inter и Palanquin Dark (OFL)
```

## Как поменять вопросы

Отредактируйте `data/trainer.json`: `taskText` — текст задания перед словом, `questions` — список вопросов с путём к картинке (`image`) и правильным ответом (`answer`). Количество страниц в навигации подстраивается под число вопросов.

## Возможности

- вопросы перемешиваются при каждом запуске и перезапуске;
- после последнего вопроса открывается `pages/answers.html`; крестик на ней возвращает к новому прохождению;
- страницы открываются по мере прохождения, к пройденным можно вернуться и изменить ответ;
- ответ проверяется без учёта регистра и пробелов по краям;
- в поле ввода можно вводить только кириллицу, пробел и дефис;
- интерфейс масштабируется от 1200px до 4K, есть вёрстка для смартфонов в портретной ориентации;
- перетаскивание изображений отключено.
